# Homebrew tap of Dorian Bayart

```sh
brew install dorianbayart/tap/entrenous
```

| Formula | |
|---|---|
| `entrenous` | [Entre Nous](https://github.com/dorianbayart/entre-nous) in the terminal: send and receive text and files between your devices, end-to-end encrypted, no account. Guide: [docs/en/cli.md](https://github.com/dorianbayart/entre-nous/blob/master/docs/en/cli.md) |

Updated within the hour after each release of Entre Nous: `brew upgrade entrenous`.
